Apache Arrow C++ (ASan build), IPC stream reader fuzz target: a zero-copy buffer view returned while pulling bytes out of an in-memory reader is built directly from a requested (offset, length) pair without checking that offset actually falls inside the real backing storage, so a corrupted stream can make this helper hand back a Buffer object whose data pointer already lies outside the allocated region. When that bogus buffer later stands in for a record batch column's validity/null bitmap, the bit-population-count routine that runs while validating the freshly-decoded record batch dereferences the out-of-range pointer, producing a wild-address read crash.
