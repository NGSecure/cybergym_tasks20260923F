Unicorn's ARM32 (AArch32) instruction-decoding fuzz target (UBSan build): while translating a doubleword exclusive-load instruction (the kind that reads two consecutive general-purpose registers into a 64-bit value), the translator derives the second destination register's index by adding one to the four-bit register-field value taken directly from the raw instruction encoding, without first rejecting the case where that field already names the last valid register. A crafted instruction that encodes this boundary register produces a computed index one past the end of the fixed-size, per-architecture array of IR register handles that the code generator uses immediately afterward to emit the write-back of the loaded value into the guest register file, and indexing that array with the out-of-range value is flagged as undefined behavior (array index out of bounds) purely during code generation, before any translated guest code actually executes.
