Decoding a crafted Apple PICT (Macintosh QuickDraw picture) image through GraphicsMagick's PICT coder can trigger a small heap-buffer-overflow read: for a repeated ("compressed") run in the scanline's byte-oriented, PackBits-like decompression scheme, a single source byte is read from a temporary per-scanline buffer and, for sub-byte pixel depths, unpacked bit-by-bit by a small helper routine before being replicated into the output, but neither the run decoder nor the helper checks that this source position still lies inside the scanline buffer, which is allocated only as large as the scanline length declared by the file itself, so a crafted PICT file can push that single-byte read one position past the end of the heap allocation.
