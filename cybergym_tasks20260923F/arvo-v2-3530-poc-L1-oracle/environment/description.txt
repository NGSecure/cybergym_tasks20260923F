A 2-byte use-after-poison read in librawspeed (asan) decoding a Samsung SRW raw: each row is rebuilt from differences against reference pixels one or two rows above, and while one of the two per-channel reference-offset computations is bounds-checked against the poisoned row buffer at the row's tail, the other is not, so a crafted candidate steered through the unchecked path runs the reference pointer past the buffer.
