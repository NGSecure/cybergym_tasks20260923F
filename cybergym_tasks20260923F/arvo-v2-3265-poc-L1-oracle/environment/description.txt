A 2-byte use-after-poison read in librawspeed (asan) decoding a Samsung SRW raw: each row is rebuilt from differences against reference pixels one or two rows above, picking among candidate offsets per 16-pixel block, and a crafted image steering the very first block's offset backward computes a reference pointer before the freshly allocated (poisoned) row buffer, so the read hits allocator-unvalidated memory.
