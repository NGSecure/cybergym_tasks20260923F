Decoding a crafted Apple PICT (Macintosh QuickDraw picture) image through GraphicsMagick's PICT coder can trigger a heap-buffer-overflow read: the scanline run-length decompressor (a byte-oriented, PackBits-like scheme) treats an attacker-controlled control byte as an unconditional literal-run length and copies that many following bytes straight out of a temporary per-scanline buffer into the output pixel buffer, without ever checking that the run stays within that scanline buffer, which is allocated only large enough for the scanline length declared by the file itself, so a crafted PICT file can drive that copy past the end of the heap allocation.
